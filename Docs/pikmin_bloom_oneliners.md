# Pikmin Bloom 一句話說明（31 句）

## 核心梗定義

| 梗 | 意思 |
|---|---|
| 走路 | 累積步數，讓培育槽裡的花苗長大 |
| 拔苗 | 花苗步數走滿後，把皮克敏拔出來加入隊伍 |
| 種花 | 開啟種花模式，用花瓣沿路種花；大家在同一處種花可讓巨大花束盛開 |
| 拉花 | 巨大花束盛開後，在花上往下拉，收集精華（每次盛開只能拉一次） |
| 搶蘑菇 | 蘑菇免費名額只有 5 個、每天 3 次，熱門地區常常搶不到 |

## 驗證器

每一句都必須通過：

1. **核心梗**：至少扣到走路、拔苗、種花、拉花、搶蘑菇其中一個。
2. **機制正確**：不能出現遊戲裡沒有的設定。
3. **拉花用法**：只指「往下拉巨大花束收精華」，不能當成作畫或摘皮克敏頭上的花。
4. **版本標籤**：每句開頭標明是什麼版本。

## 31 句

1. **反差版：** 表面上是療癒散步遊戲，其實是一場每天搶蘑菇、拉巨大花束的資源戰。
2. **生活比喻版：** 像帶一群小朋友去郊遊，你走路他們長大，看到巨大花束一起去拉，看到蘑菇一起衝。
3. **健身版：** 唯一能讓人主動多走兩站、提早下車的健身教練，報酬是口袋裡的花苗。
4. **計步器版：** 計步器告訴你走了幾步，皮克敏告訴你這幾步換來幾個小孩。
5. **生產版：** 走路是懷孕，拔苗是生產，一天可以生好幾胎。
6. **成語版：** 全世界唯一鼓勵揠苗助長的遊戲，拔出來的苗還會跟著你走。
7. **價目表版：** 別人說一萬步是健康目標，皮友說一萬步是一隻皮克敏的價錢。
8. **浪漫版：** 你走過的路不留腳印，只留下一排花。
9. **通勤版：** 把每天無聊的上下班路線，種成一條只屬於你的花道。
10. **團結版：** 一個人種花是一條花路，一群人在同一處種花，就能種出一朵巨大花束。
11. **前人種樹版：** 你今天拉的巨大花束，是一群陌生人昨天一起種出來的。
12. **秋收版：** 巨大花束盛開時往下一拉，精華就落進口袋，這就是皮友的收成。
13. **限量版：** 每朵巨大花束一次盛開只能拉一次，錯過就等它謝了再開。
14. **雷達版：** 皮友出門不看景點，只看地圖上哪裡有巨大花束開了還沒拉。
15. **循環經濟版：** 走路拔苗、餵精華摘花瓣、花瓣拿去種花、種出巨大花束再拉回精華。
16. **時機版：** 巨大花束剛開的那一小時最閃亮，趕去旁邊種花還能多拉一顆果。
17. **戰場版：** 種花是佛系，搶蘑菇是戰場。
18. **搶票版：** 平常溫柔散步的皮友，看到蘑菇快被打掉，眼神會變得像在搶演唱會門票。
19. **台北版：** 在台北搶蘑菇的難度，大概跟尖峰時間在捷運上搶到座位差不多。
20. **座位版：** 一顆蘑菇只有 5 個免費座位，晚一步就只能看別人的 Mii 排排站。
21. **倒數版：** 真正的皮友不是在等蘑菇，是在等蘑菇被打倒後重生的那 5 分鐘。
22. **健忘版：** 官方每月提醒先餵主花精華再打蘑菇，皮友每月都說：能搶到就不錯了。
23. **額度版：** 一天只有 3 次免費蘑菇，皮友用起來比信用卡額度還謹慎。
24. **禿頭版：** 花瓣摘太兇，皮克敏禿頭給你看，上了蘑菇戰場也打不動。
25. **一日行程版：** 早上走路養苗，中午拔苗收兵，下午種花拉花，晚上搶蘑菇。
26. **特種部隊版：** 從拔苗到種花都像養盆栽，直到地圖冒出一顆蘑菇，大家瞬間變特種部隊。
27. **皮克敏視角版：** 皮克敏的一生只有三件事：被你拔出來、陪你種花、被派去打蘑菇。
28. **補給版：** 精華不夠？去拉巨大花束；巨大花束拉完了？去搶蘑菇。
29. **社區版：** 同一條街的皮友互不認識，卻一起種出巨大花束、一起圍攻同一顆蘑菇。
30. **反差版二：** 畫風是兒童繪本，玩家日常是巡邏巨大花束、卡位蘑菇的資源管理。
31. **總結版：** 走路、拔苗、種花、拉花、搶菇。
